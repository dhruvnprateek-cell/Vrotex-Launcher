# Vortex Launcher program information

This directory contains the application's platform metadata and branding assets:

- desktop-entry, MIME, AppStream and bundle resources;
- Vortex Launcher icons and Windows installer definitions;
- licensing information for bundled fonts and inherited code/assets.

The launcher preserves attribution and applicable upstream licenses for its
Prism Launcher, PolyMC, and MultiMC-derived components.
